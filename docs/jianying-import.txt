【剪映 / CapCut 草稿包使用说明】

ℹ 如未额外注明，本草稿包格式一般仅在剪映专业版 5.9 上测试过；其他版本可能兼容，请自行验证。

1. 解压本 ZIP，得到以项目命名的文件夹（内含 draft_content.json、draft_meta_info.json、media、timeline.json）。
2. 将整个文件夹放入剪映专业版草稿目录，或在剪映中使用「导入草稿」选择该文件夹（视版本而定）。
3. 素材路径已尽量写为相对路径（media/clip_XXX.mp4）。若提示媒体丢失，请手动指向解压目录下的 media 文件夹。
4. timeline.json 为时间轴索引（片段顺序、时长、所属分集），便于核对或二次处理。
