# 第一集剧本

作品名：麒麟才子  
来源议题：用 XCanvas 制作《琅琊榜》第一集

大雪封城，江左盟密舟夜泊金陵。身负旧案血仇的谋士 @梅长苏 以病弱之躯入京，借「苏哲」之名投亲说医，实为暗查当年冤案。他刚入城便与巡城的旧友 @萧景琰 车驾擦肩，只因面目全非，未能相认。与此同时， @柳舵主 奉命放出风声，引朝堂注意。滨州侵地案卷宗被人调包，六部暗线浮动。 @梅长苏 递帖入宫，在御前轻描淡写点破卷宗破绽，满朝皆惊。 @萧景琰 闻讯追查，两人在宫门雪阶擦肩，一个不敢认，一个不能认。收束于 @梅长苏 咳血回望，低语「金陵，我回来了」。

## 场次

1. 大雪封城，密舟夜泊金陵
2. 梅长苏以苏哲之名入京
3. 城门口与萧景琰车驾擦肩，未能相认
4. 柳舵主放风，引朝堂注意
5. 滨州侵地案卷宗被调包
6. 梅长苏御前点破卷宗破绽
7. 宫门雪阶再遇，一个不敢认，一个不能认
8. 梅长苏咳血回望：「金陵，我回来了」
